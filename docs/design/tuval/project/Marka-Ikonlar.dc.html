Icon library

45 line icons and 6 animated icons, all drawn on the same grid with the same stroke. Screens take their icons from here. An icon supports the label; it never replaces it.

Drawing rules

  • Grid 24 units; at least 3 units of padding from the edge.
  • Stroke 2 units; round caps and joins.
  • Fill none. The one exception is the play triangle.
  • Color the color of the text beside it. A status icon takes its status color: warn for a problem, accent text for progress.
  • Size 18 px in text, 22 in buttons, 26 in the play button.

Animated icons

  • generating
  • done
  • uploading
  • downloading
  • generating audio
  • running
  • They only report. An animated icon says "something is happening" or "this just finished". No icon spins or bounces for decoration.
  • They play while the job runs. A finished job draws once and stops; it loops here only as a demo.
  • They stop under reduced motion. If the device asks for reduced motion, the still version shows; the meaning stays in the label beside it.

An icon without a label has a name.

An icon button that stands alone gets a hidden name for screen readers and takes up at least 44 px.

One meaning, one icon.

The same icon is never used for two different jobs. If an icon is missing, it is drawn here first, by the same rules.

No emoji, no colored icons.

An icon is not decoration. It is never placed beside a headline or in a card corner as filler.
