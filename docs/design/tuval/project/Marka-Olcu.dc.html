Scale

Spacing, corners, and control heights are each a short ladder. No value is used between the steps. The ladder applies to the product screens. These brand boards are laid out more loosely.

Page and grid

  • Margin 4% of the screen; 16 px minimum, 60 px maximum.
  • Top bar 80 px, one line below it. The same on every page.
  • Video grid columns at least 210 px; 16 between columns, 32 between rows. The width decides how many columns fit.
  • Two-column page narrow column 240–400 px, the wide column takes the rest. They stack on a narrow screen.
  • Reading width text stays within 620 px, legal text within 760 px.
