One primary button per screen. A button says what it does and keeps its name through the whole flow. In a list or a table, a row action that takes you somewhere (Open, View) is a link; one that changes something (Refund, Retry) is a bordered button. Lime fill is for the one main action of the screen; the one other place is the selected category in the gallery filter.

Removing something: the safe choice is the wide bordered button; the removing one is narrow with a warn border. No lime in these dialogs.
