The first column names the row and is darker. Number columns are right-aligned in tabular figures. A status is a shape and a word, never color alone. The row action sits in the last column: a link if it takes you somewhere (Open, View), a bordered button if it changes something (Refund, Retry). On a narrow screen the table scrolls sideways inside its own box; the page does not. Under the table: how many rows are shown, then Previous and Next.
